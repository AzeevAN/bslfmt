# Fixtures

Небольшие синтетические примеры для тестов процедур, функций, циклов, условий,
комментариев, аннотаций и многострочных запросов. Реальные выгрузки сюда не
копируются.

`style-v0.json` — пары `input`/`expected` для выбранного первого стиля. Они
проверяются в `tests/test_formatter.py`. Каждая новая фикстура должна оставаться
синтетической и проходить просмотр перед добавлением.
